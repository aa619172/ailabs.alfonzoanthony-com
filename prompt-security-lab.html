BEFORE / AFTER
The prompt architecture is the experiment.

    

      
PROMPT-ARCH-V1 · Baseline
Prompt behavior is under-specified.
  • Weak instruction hierarchy
  • Context-use and disclosure boundaries are blurred
  • Retrieved and peer-agent text can gain too much authority
  • Tool choice and parameters are under-constrained
  • Schema and transformation rules are soft preferences
12/12 controlled failures · risk 84

      
PROMPT-ARCH-V2 · Hardened
Prompt behavior has explicit contracts.
  • Trust-ranked instruction conflict resolution
  • Context-use and disclosure permissions are separated
  • Retrieved and peer-agent content is treated as untrusted by default
  • Tool authorization and parameter validation live outside free-form prompting
  • Schema, refusal, and policy-preservation invariants are regression tested
0/12 controlled failures · risk 0
