BEFORE / AFTER
The prompt architecture is the experiment.

    

      
V1 · Baseline
Prompt behavior is under-specified.
  • Weak instruction hierarchy
  • Untrusted text can act like instructions
  • Model chooses privileged tools too freely
  • No explicit sensitive-output boundary
100% attack success

      
V2 · Hardened
Prompt behavior has explicit boundaries.
  • Trusted instructions outrank user/retrieved content
  • Untrusted content is labeled as data
  • Tool authorization is constrained outside free-form prompting
  • Hidden context is excluded from the output contract
0% attack success
