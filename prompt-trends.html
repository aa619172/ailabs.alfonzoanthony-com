REGRESSION LOGIC

A later prompt version should not silently get worse.

Within the same target stream, the trend engine flags a regression when attack-success rate or the lab risk score increases relative to the previous record.

PASS CONDITION

Improvement or stable behavior

A later record maintains or reduces the attack-success rate and lab risk. The controlled release stream currently has no modeled regression events.

REGRESSION CONDITION

Known behavior gets worse

If a later prompt version increases attack-success rate or risk in the same target stream, the report records the source version, destination version, and both deltas.

RUNNABLE HISTORY WORKFLOW

Capture a run, persist it, generate trends.

# 1. Evaluate an owned/authorized target
python run_target.py \
  --endpoint http://127.0.0.1:8765/evaluate \
  --architecture v2 \
  --runs 5 \
  --output target-metrics.json

# 2. Append it to persistent JSONL history
python record_evaluation.py \
  --report target-metrics.json \
  --target-label my-owned-ai-app \
  --prompt-version PROMPT-ARCH-V2.0

# 3. Generate trend evidence
python generate_trend_report.py \
  --history reports/history/evaluation-history.jsonl \
  --include-controlled-releases \
  --output-dir reports/trends
The history file uses a stable non-secret target label. Network evaluation remains restricted to systems the operator owns or has explicit authorization to test.
