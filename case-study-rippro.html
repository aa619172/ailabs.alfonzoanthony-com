Case study

Crusoe RipPro Studio

AI-assisted DTF/DTG print-preparation software designed around the operator’s real production flow: artwork, presets, printer setup, calibration, queues, automation, and reprints.

AI-assisted developmentPythonPySide6OpenCVDTF/DTGUX workflow

The problem

DTF and DTG operators often move between artwork tools, printer utilities, folders, presets, calibration screens, queue managers, and previous job files. Repetitive setup and fragmented software can waste time, media, ink, and attention.

User pain points

  • Repeated substrate and printer setup.
  • Artwork intake, queues, and calibration live in separate places.
  • Incorrect presets or alignment can waste materials.
  • Recreating previous customer jobs takes unnecessary time.
  • Manual file intake becomes a bottleneck as volume grows.

The solution

I used prompt-driven AI development to translate print-production knowledge into a centralized desktop experience. RipPro Studio organizes the most common tasks into a dashboard with Canvas, Queues, Presets, Printers, Calibration, Hot Folders, Jobs, and Settings.

Workflow-first UX

The interface is organized by real operator tasks rather than a collection of unrelated technical settings. New artwork can enter through Import Artwork, recurring configurations live in Media Presets, alignment moves directly to Calibration, and prior jobs can be reopened from Job History.

Hot-folder automation

Hot folders reduce repetitive file handling by allowing incoming artwork to enter a predefined processing workflow automatically—especially useful for production environments receiving many jobs.

What this demonstrates

Domain-specific product thinking, prompt engineering, UX architecture, desktop application design, and the ability to turn specialized operational pain points into a coherent software workflow.
