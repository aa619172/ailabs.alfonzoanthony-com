Case study

AI Video Generation Engine

A structured generative-media pipeline connecting Gemini script generation to machine-readable output parsing and downstream video generation.

n8nGeminiStructured outputPrompt chainingGenerative video
Project scope: This is a separate n8n build. The Meta reach and ad-spend result belongs only to the 2TimesACharm AI Ad Engine.

The problem

AI can write scripts and AI can generate video, but creators still lose time copying content between systems, reformatting responses, and correcting inconsistent structures.

User pain points

  • Manual copy-and-paste between AI tools.
  • LLM output structures can vary between runs.
  • Scaling one-off workflows creates repetitive work.
  • Downstream tools need predictable data, not only readable prose.

The solution

I built an n8n pipeline in which a Gemini-powered script step produces content that is validated by a Structured Output Parser before being passed into video generation.

TriggerGemini scriptStructured parserValidated payloadVideo generation

Why structured output matters

A response can look good to a person and still fail automation if fields move, headings change, or expected values are missing. The parser gives the next node a predictable contract.

Prompt approach

The prompt can define scene structure, narrative sequence, tone, visual instructions, content constraints, and expected fields. The output is designed for the next system as well as the human user.

What this demonstrates

LLM orchestration, prompt chaining, structured outputs, n8n automation, generative-media workflow design, and AI-to-AI handoffs.
